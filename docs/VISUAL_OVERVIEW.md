## Data Flow

```
User Types "school" in Search
        ?
    [500ms debounce]
        ?
filter-enhancements.js captures input
        ?
enhancedFilters.search = "school"
        ?
buildEnhancedExpenseQuery() builds URL params
        ?
loadData() makes API call
        ?
GET /api/expenses?search=school&...
        ?
server.js processes request
        ?
SQL: WHERE (description LIKE '%school%' OR ...)
        ?
Database returns matching rows
        ?
applyClientSideFilters() applies any client-side filters
        ?
renderExpenses() displays results
        ?
renderFilterChips() shows active filters
        ?
updateEnhancedFiltersLabel() shows "1 filter active, 15 results"
```

## Performance Optimization

```
User Types ? "s" ? "c" ? "h" ? "o" ? "o" ? "l"

Without Debounce (BAD):
  's'     ? API call 1
  'sc'    ? API call 2
  'sch'   ? API call 3
  'scho'  ? API call 4
  'schoo' ? API call 5
  'school'? API call 6
  Total: 6 API calls ??

With Debounce (GOOD):
  's'     ? timer starts
  'sc'    ? timer resets
  'sch'   ? timer resets
  'scho'  ? timer resets
  'schoo' ? timer resets
  'school'? timer resets
  [500ms passes]
  ? API call with "school"
  Total: 1 API call ??

Press Enter (BEST):
  's' 'c' 'h' 'o' 'o' 'l' [Enter]
  ? Immediate API call
  No waiting! ?
```
